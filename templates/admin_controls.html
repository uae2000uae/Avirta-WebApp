Avirta has one design with a light mode and a dark mode. Each visitor's device decides by default; anyone can switch with the button in the header, and the choice is remembered on that device. Sound effects can be muted with the button next to it.

These buttons change the mode on this browser only. There are no site-wide colour themes any more.
